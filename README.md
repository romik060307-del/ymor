# ymor

ymor adalah fork dari [Metrolist](https://github.com/MetrolistGroup/Metrolist) (klien YouTube Music
untuk Android) dengan nama, ikon, dan tampilan default yang diubah.

**Lisensi:** GPL-3.0, sama seperti proyek asalnya. Seluruh kode sumber ada di repositori ini, dan
hak cipta Metrolist serta kontributornya tetap berlaku. Lihat `LICENSE`.

## Perubahan dari Metrolist
- Nama aplikasi `ymor`, application ID `com.ymor.app`
- Ikon baru: huruf "y" kuning di latar putih
- Latar pemutar default: blur artwork
- Pembaruan otomatis dimatikan (agar tidak menawarkan APK Metrolist)

## Build
Buka tab **Actions → Build ymor APK → Run workflow**. APK ada di Artifacts setelah selesai.

## Catatan
Aplikasi ini mengakses YouTube Music, yang mungkin melanggar ketentuan layanan YouTube.
Gunakan dengan risiko sendiri.
